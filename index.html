Nuestro Servidor HTTP

HTTP (HyperText Transfer Protocol) es el protocolo de comunicación que permite la transferencia de datos en la web; funciona bajo el modelo cliente–servidor, donde el navegador envía peticiones GET y el servidor responde con el recurso solicitado y un código de estado (200, 404, etc.). Esta página está siendo servida por Apache2 ejecutándose sobre Linux (Lubuntu), lo que convierte la máquina virtual en un servidor web real accesible desde cualquier equipo de la red local.
